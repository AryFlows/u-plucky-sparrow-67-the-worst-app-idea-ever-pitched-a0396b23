One-sentence pitch for the worst app imaginable: **UmbrellaAlert** — an app that notifies you every time it rains anywhere on Earth except where you are, so you can always feel prepared for weather you will never experience.

Run: `node main.ts` (Node 22, stdlib only). Writes the pitch to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
